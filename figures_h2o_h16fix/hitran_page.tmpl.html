H₂O line lists and the temperature-index fix

From November 2020 until September 2026, ExoRT's HITRAN-2016 water-vapour table was offset by one 25 K temperature slot: the slot labelled T held the absorption at T − 25 K, about 20 % too weak. Wolf et al. (2022) Fig. 1 used that table. This page compares the table with the error, the corrected HITRAN-2016 table and the HITRAN-2024 table now in v2, and shows the evidence for the offset.

Where the difference is, at 300 K

Each HITRAN-2016 run minus the HITRAN-2024 run, band by band, for the TS300K column. The corrected HITRAN-2016 table sits almost on top of HITRAN-2024 everywhere, so the old OLR bias came from the index error, not from the line-list revision. In the near-UV bands HITRAN-2024 adds real water lines that HITRAN-2016 lacks (it stops at 25,711 cm⁻¹).

Evidence for the offset

The table with the error still carries the temperature labels it was written with in 2020. They repeat 100 K and stop at 475 K, while ExoRT always read the table as the nominal 100–500 K grid:

Median |Δ ln k| over all pressures, g-points and 150–475 K. The table with the error matches the independent run only after a 25 K shift; the corrected table matches at the labelled temperature.

Reading these

Where it was fixed

main is fixed as v1.1.0; v1.0.0 keeps the original table. On the v2 branch the table with the error is kept as …_grrtm_Tindex-error.nc, which the k-file grid check now refuses to load.

Why validation never caught it

Against LBLRTM, OLR errors went from −0.8 … +2.8 to −0.6 … −3.9 W m⁻². Both are within the usual correlated-k scatter, so the comparison could not tell the tables apart. The labels in the file could.
